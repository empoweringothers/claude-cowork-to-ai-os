# Acknowledgments

This implementation is original, but the project benefited from studying these
MIT-licensed or publicly documented projects:

- [kenn-io/agentsview](https://github.com/kenn-io/agentsview): Cowork discovery,
  nested native transcript handling, subagent awareness, and symlink-containment
  tests.
- [looptech-ai/cowork2code](https://github.com/looptech-ai/cowork2code): the
  observation that Cowork can contain a native Claude Code JSONL transcript and
  the value of a source-read-only workflow.
- [PeriChu/claude-cowork-export](https://github.com/PeriChu/claude-cowork-export):
  multi-format archival, `spaces.json` mapping, and a reviewable continuation
  seed.
- [quinnjr/claude-code-profiles](https://github.com/quinnjr/claude-code-profiles):
  explicit separation of personal and work Claude Code state.
- [rogermmf/claude-migrator](https://github.com/rogermmf/claude-migrator):
  format-version checks, path translation, preview reports, and excluding
  machine-bound credentials.
- [empoweringothers/pastor-sermon-ai-setup](https://github.com/empoweringothers/pastor-sermon-ai-setup):
  pinned-release, checksum, recovery, and one-step-at-a-time public setup
  patterns.
- [empoweringothers/vfb-ai-brain](https://github.com/empoweringothers/vfb-ai-brain):
  person-first AI Brain structure, permissions, provenance, and private-data
  boundaries.

No authentication-copy, browser-state merge, source purge, or live Cowork
database-writing feature from adjacent projects is included here.
