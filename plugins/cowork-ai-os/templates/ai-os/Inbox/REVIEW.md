# Review queue

For every proposed promotion, record:

- Status: `review`, `approve`, `edit`, or `reject`
- Proposed destination
- Candidate statement
- Opaque source and message locator
- Evidence type: explicit or inferred
- Freshness/conflict note
- Sensitivity note

No candidate has been approved yet.

## Entry format

Add one `## Candidate <number>` heading per candidate, followed by the fields
above. Verification counts candidates with `review`, `edit`, or missing status
as unreviewed; `approve` and `reject` are resolved.
