# Permissions

## Always allowed

- Read the reviewed AI OS files relevant to the current request.
- Search and summarize selected local material.
- Draft internal files inside this AI OS.
- Run the bounded task-metadata doctor, allowlisted inventory, and verification
  checks after confirming the active account and privacy profile.

## Requires explicit approval

- Read content from additional sessions or linked folders.
- Promote imported material into current instructions, identity, state, or
  decisions.
- Install or execute imported code, skills, hooks, or plugins.
- Send, publish, share, change access, delete, or modify an external system.

## Never automatic

- Access or copy authentication state.
- Write into the Cowork source store.
- Mix personal and work profiles.
- Hide uncertainty or source conflicts.
